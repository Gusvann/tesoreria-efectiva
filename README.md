# Tesorería efectiva

Demo frontend de tesorería con cuatro vistas: **Dashboard, Bancos, Movimientos y Escenarios**.

Este repositorio es independiente de **Forecast Minimalista**. No utiliza Supabase, bases de datos, servidor de aplicación ni inicio de sesión.

## Datos temporales

Los ejemplos son ficticios: 3 cuentas, 21 movimientos y 3 escenarios. Los cambios se conservan exclusivamente en la memoria de la pestaña actual y se descartan al recargar, cerrar o reiniciar el ejemplo. No utilices información financiera real.

## Estado de publicación

La carga del código y la verificación del despliegue están en curso. La configuración de GitHub Pages se comprobará después de cargar y ejecutar las pruebas.
